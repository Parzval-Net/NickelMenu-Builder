Instrucciones de Instalación

              

                
    
                  
  1. Conecta tu dispositivo Kobo al ordenador mediante USB.
    2. 
                  
  2. Descarga la configuración (se crea como config sin extensión) y cópiala a KOBOeReader/.adds/nm/config.
    3. 
                  
  3. ¿Subiste un icono PNG? Copia ese archivo a KOBOeReader/.adds/nm/icon/.laptopbook.png.
    4. 
                  
  4. Si completaste la información del propietario, crea o actualiza KOBOeReader/.adds/owner.sh con el script mostrado en la vista previa.
    5. 
                  
  5. Expulsa el Kobo de forma segura y espera a que NickelMenu recargue la configuración.
    6. 
                

              

            

          

          

            
            
          

        

      


    

  


  
  

    

    

      

        
¡Bienvenido a NickelMenu Builder! 🎉

        
      

      

        

          

            
🚀 ¿Qué es NickelMenu Builder?

            
Una herramienta intuitiva para crear menús personalizados en tu dispositivo Kobo eReader. Con esta app puedes agregar funciones adicionales como reiniciar, cambiar modo oscuro, importar libros y mucho más.

          

          
          

            
📱 ¿Cómo funciona?

            
    
              
  1. Selecciona contextos: Elige dónde quieres que aparezca tu menú (menú principal, lector, biblioteca, etc.)
    2. 
              
  2. Elige acciones: Selecciona las funciones que necesitas del catálogo
    3. 
              
  3. Personaliza: Ajusta nombres y opciones según tus preferencias
    4. 
              
  4. Exporta: Descarga el archivo config y cópialo a tu Kobo
    5. 
            

          

          
          

            
💡 Consejos para empezar

            
    
              
  • Personaliza iconos Unicode: Cambia los símbolos de tus acciones favoritas
    • 
              
  • Información del propietario: Edita tus datos personales para mostrar en el dispositivo
    • 
              
  • Iconos personalizados: Sube tu propio icono para el menú principal
    • 
              
  • La vista previa te muestra cómo se verá en tu Kobo
    • 
              
  • Puedes copiar y exportar tu configuración fácilmente
    • 
            

          

          
          

            
📋 Instalación en tu Kobo

            
    
              
  1. Conecta tu Kobo al ordenador
    2. 
              
  2. Copia el archivo generado como KOBOeReader/.adds/nm/config (sin extensión)
    3. 
              
  3. Expulsa el dispositivo de forma segura
    4. 
              
  4. ¡Tu menú personalizado estará disponible!
    5. 
            

          

          
          

            
⚠️ Importante

            
Esta herramienta es no oficial y no está afiliada a Kobo ni a pgaskin. Úsala bajo tu propia responsabilidad. Siempre haz una copia de seguridad antes de modificar tu dispositivo.

          

        

      

      

        
        
      

    

  

  
  

    

    

      

        
Guía de Uso

        
      

      

        

          

            
🚀 Flujo rápido

            
    
              
  1. Selecciona uno o varios contextos en el Paso 1. Usa la tarjeta “Todos los contextos” si quieres activarlos de una vez.
    2. 
              
  2. Explora las pestañas de acciones, busca por nombre o etiquetas y marca las que necesites.
    3. 
              
  3. Personaliza en el Paso 3: asigna iconos Unicode, sube un icono PNG opcional y completa la información del propietario.
    4. 
              
  4. Valida, copia o exporta tu configuración desde el Paso 4 y sigue las instrucciones de instalación.
    5. 
            

          


          

            
🧰 Funciones disponibles

            
    
              
  • Selección múltiple de contextos con sincronización visual y vista previa en vivo.
    • 
              
  • Catálogo organizado en pestañas, buscador en tiempo real y acciones destacadas.
    • 
              
  • Plantillas predefinidas para comenzar rápido y opción de importar configuraciones existentes.
    • 
              
  • Galería de símbolos Unicode con asignación rápida y vista previa inmediata.
    • 
              
  • Subida de icono PNG (64×64, <10KB) y edición del archivo owner.sh con tus datos.
    • 
              
  • Vista cruda del archivo, validación automática y tema claro/oscuro con un clic.
    • 
            

          


          

            
📥 Instalar en tu Kobo

            
    
              
  1. Conecta tu dispositivo Kobo al ordenador mediante USB.
    2. 
              
  2. Descarga la configuración (el archivo se llama config sin extensión) y cópiala a KOBOeReader/.adds/nm/config.
    3. 
              
  3. Si subiste un icono, cópialo a KOBOeReader/.adds/nm/icon/.laptopbook.png. Si generas el script del propietario, crea o actualiza KOBOeReader/.adds/owner.sh con la vista previa.
    4. 
              
  4. Expulsa el Kobo de forma segura y espera a que se reinicie NickelMenu.
    5. 
            

          


          

            
✨ Trucos y recomendaciones

            
    
              
  • Valida siempre antes de exportar para detectar errores comunes.
    • 
              
  • Usa “Ver código” para revisar o copiar rápidamente el archivo completo.
    • 
              
  • Prueba distintas combinaciones de contextos para descubrir acciones nuevas.
    • 
              
  • Activa el tema oscuro desde la cabecera si trabajas en ambientes con poca luz.
    •
